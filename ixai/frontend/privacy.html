개인정보 처리 안내

시행일: 2026년 11월 21일

이 안내는 이 웹사이트가 계정, 대화, 기억, 학습 자료를 어떻게 다루는지 설명합니다. 이 서비스의 답변 생성과 모델 학습은 자체 서버의 PyTorch 신경망에서 이루어지며 외부 AI 추론 API를 사용하지 않습니다.

저장하는 정보

  • 계정을 만들면 로그인 이메일 주소, 입력한 이름과 나이, 비밀번호의 해시, 이용정책 동의 시각과 정책 버전을 저장합니다. Google로 로그인하면 Google의 고유 계정 식별자와 확인된 이메일 주소를 저장합니다. Google 비밀번호나 Google 토큰은 저장하지 않습니다.
  • 서비스 제공을 위해 사용자가 보낸 메시지와 AI 답변, 사용자가 직접 저장한 기억, 피드백, 사용자가 동의해 제출한 텍스트와 문서에서 추출한 내용을 저장합니다.
  • 데이터베이스와 모델 체크포인트는 서비스를 운영하는 서버의 설정된 저장소에 보관됩니다. 운영 환경의 백업과 접근 관리는 서비스 운영자가 맡습니다.

대화와 학습 데이터

대화 내용은 자동으로 모델 학습에 사용하지 않습니다. 사용자가 학습 사용에 명시적으로 동의하고 관리자가 승인한 자료만 학습 대상으로 처리합니다. 프로젝트에 포함된 자체 작성 기초 자료는 서비스의 최초 학습에 사용됩니다.

승인된 자료는 여러 사용자가 함께 이용하는 모델의 가중치에 반영될 수 있습니다. 원본 자료를 삭제해도 이미 학습된 내용이 모델 가중치에서 즉시 제거되지는 않습니다. 운영자는 남은 자료로 재학습하거나 이전 모델 버전으로 복구할 수 있지만, 완전한 제거를 보장할 수는 없습니다. 민감한 개인정보는 학습 자료로 제출하지 마세요.

Google 로그인

Google 로그인을 선택한 경우 로그인 처리를 위해 Google에 연결합니다. 이 앱은 `openid`, `email`, `profile` 범위만 요청하며 Drive, Gmail 등 다른 Google 데이터에는 접근하지 않습니다. Google은 자체 개인정보 처리방침에 따라 로그인을 처리합니다.

이용자의 선택

사용자는 웹사이트에서 자신의 대화, 기억, 제출한 학습 자료를 확인하거나 삭제할 수 있습니다. 계정 및 개인 데이터를 삭제하면 해당 계정에 연결된 원본 기록을 삭제합니다. 이미 모델 가중치에 반영된 정보에는 위의 학습 데이터 안내가 적용됩니다.

보관 및 보안

계정과 연결된 정보는 사용자가 삭제를 요청하거나 서비스 운영자가 저장 목적을 종료할 때까지 보관됩니다. 서버 운영자는 계정별 데이터 접근을 제한하고 비밀번호를 원문으로 저장하지 않습니다. 인터넷에 공개된 운영 사이트에서는 HTTPS와 서버 접근 제어를 구성해야 합니다.
