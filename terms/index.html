iX 이용정책

시행일: 2026년 11월 21일

ixaistudio는 자체 PyTorch 신경망과 사용자가 승인한 자료를 이용해 운영하는 실험적 대화 서비스입니다. 가입하거나 서비스를 이용하면 아래 정책을 확인하고 동의한 것으로 처리됩니다.

계정과 이용

  • 본인의 계정과 로그인 정보를 안전하게 관리하고, 타인의 계정에 접근하거나 서비스를 방해하지 마세요.
  • 서비스를 불법적인 목적, 타인에 대한 피해, 개인정보 침해, 악성 코드 배포에 사용하지 마세요.
  • 입력한 자료를 학습 데이터로 제출할 때는 해당 자료를 사용할 권한이 있고 학습에 동의했는지 확인하세요.

대화와 학습

AI 응답은 자체 소형 모델이 생성하며 정확성이나 완전성을 보장하지 않습니다. 중요한 판단은 답변만으로 내리지 마세요. 일반 대화는 자동으로 학습하지 않습니다. 학습 자료는 사용자가 명시적으로 승인해 제출하고 관리자가 검토한 뒤에만 모델 학습에 사용합니다.

자료와 모델

제출한 학습 자료의 원본은 데이터 관리 화면에서 확인하거나 삭제할 수 있습니다. 이미 학습된 모델 가중치에서 특정 자료의 영향을 즉시 제거할 수는 없습니다. 운영자는 시스템 보안과 안정성을 위해 서비스 기능을 변경하거나 일시 중단할 수 있습니다.

문의

계정, 개인정보, 이용정책 관련 문의는 로그인 화면에 표시되는 지원 연락처를 이용하세요.
